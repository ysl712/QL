小猪提醒

给 AI 的小猪账本说明

账单保存在浏览器 localStorage 的 piggy-ledger-v1 键中。当前版本不会启动网络服务，MCP 服务端不能直接访问浏览器数据。可由本机 MCP host 通过明确授权的浏览器桥接调用下方接口，或将数据 JSON 导出后交给 MCP 工具处理。

window.PiggyLedger 已预留：
getAllTransactions() · addTransaction(data)
updateTransaction(id, data) · deleteTransaction(id)
getMonthlySummary(month) · getCategoryStats(month)
getCategories()

字段格式：{ id, type, amount, category, date, note, createdAt, updatedAt }。写入操作会校验金额和必填字段。浏览器沙箱与 MCP 工具的连接需要未来配置本地桥接服务，并由用户授权。
